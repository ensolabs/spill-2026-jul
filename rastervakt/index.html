Operator’s handbook

The beam paints rows 0 through 159 from top to bottom. Each slot holds one sprite. AT 20 : S0 = A loads sprite A’s artwork and position into slot 0 just before row 20 is painted. It stays there until another write replaces it. A sprite can be loaded early. Two overlapping sprites need different slots. Writes run in raster order, with ties resolved from top to bottom in the listing.

RUN tests a whole frame. Drag Trace row to inspect the slots at a particular scanline. You can edit the listing directly and run it with Ctrl+Enter or ⌘+Enter.
